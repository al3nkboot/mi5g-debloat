# Security

Mi5G Debloat can remove or disable preinstalled system apps. That is powerful and can break a phone. Use it at your own risk, start with the Recommended tier, and keep a way to restore.

## Report a vulnerability

Please **do not** open a public issue for a security vulnerability.

Use GitHub’s private reporting form:

https://github.com/al3nkboot/mi5g-debloat/security/advisories/new

Include the app version, device and OS, and the steps to reproduce. We will try to respond promptly.

## What this project will not accept

- Requests to bypass Android, Shizuku, or OEM security
- Keystores, signing passwords, or other secrets in issues or pull requests
